## Research paper

Read the paper — `docs/research-paper.md`

The original 21-page PDF is titled “The Dual-Use Dilemma: A Comprehensive Analysis of Artificial Intelligence in Cybersecurity—Defensive Automations, Offensive Weaponization, and the Adversarial Frontier”. It covers defensive AI, offensive misuse, adversarial machine learning, governance and ethics, and includes references.

## Research question

How can the same AI methods improve cyber defense while also helping attackers and introducing risks to the models themselves? The paper examines this dual-use problem through existing literature and case discussions.

## Topics covered

| Area | Discussion in the paper |
| --- | --- |
| Evolution of defense | Signature matching, rule-based analysis and machine learning |
| Defensive AI | Security Operations Centers (SOCs), anomaly detection and behavioral biometrics |
| Offensive misuse | Deceptive content, deepfake fraud and AI-assisted malware examples |
| Adversarial machine learning | Evasion, data poisoning and model extraction |
| Governance and ethics | Risk management, bias, oversight and trust in automated systems |

Anomaly detection identifies activity that differs from an expected pattern. Evasion changes an input to mislead a model; data poisoning corrupts its training data; model extraction attempts to reproduce a model through its outputs. These topics are discussed analytically, with no attack tool included.

## Method and deliverable

The work is a literature review: it organizes and compares existing sources rather than collecting new experimental data. Its structure moves from historical context to defensive and offensive uses, model-specific attacks, governance and conclusions. The prepared Markdown copy retains page markers and the paper's reference list.
